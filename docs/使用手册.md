# 智教英航使用手册

## 一、产品定位

智教英航是面向高中英语教师的教学工作台。它围绕一节课组织工作：先了解班级学情，再确定教学目标，生成并审核教案和班级统一作业，课后整理学生作答，最后把结果沉淀到学生学习画像中。

AI提供理解、生成和分析建议；教师负责修改、审核、确认和最终教学决策。请不要把 AI 草稿直接当作正式教案或正式作业发布。

## 二、推荐演示流程

1. 进入“学情分析”，查看班级知识点表现、成绩趋势和待关注学生。
2. 进入“教学目标”，点击“新建目标”，输入本课要求，点击“解析为目标草稿”。
3. 检查教学主题、目标、重点、难点、相关班级学情和上课建议，保存后点击“教师确认目标”。
4. 进入“智能教案”，选择已确认目标，设置难度和课堂时间，点击“生成教案草稿”。
5. 修改各部分内容，提交审核并点击“教师确认教案”。确认后可以下载 PDF 或 Word。
6. 进入“智能作业”，选择同一个教学目标，设置题量和难度，点击“生成统一作业草稿”。
7. 检查题型、题干、选项、答案、知识点和解析，提交审核并点击“教师确认作业”。
8. 点击“教师发布作业”，再到“作业管理”查看作业和提交记录。
9. 选择学生，上传与本套作业对应的 Word 或文字型 PDF，点击“上传并识别”。
10. 检查待确认结果，点击“确认批改并更新画像”，再回到学生管理或学情分析查看变化。

## 三、使用注意

- 教学目标、教案和作业必须经过教师核对；系统不会自动发布。
- 作业上传文件应与当前发布的作业对应，并尽量使用可复制文字的 `.docx` 或 PDF。
- 当前图片扫描件 OCR 尚未启用，扫描图片可能无法识别。
- 演示数据为虚构学生数据。正式使用时不要录入无授权的真实学生信息。
- AI 功能需要网络和有效的 DeepSeek API 密钥。
- Windows 演示版可开启 `ZHJ_DEMO_UPLOAD=1`：仅虚构的张同学上传 PDF 时使用预设示例答案。该过程不解析 PDF 作答；教师确认后才将模拟结果写入画像，页面会持续标明“演示模拟”。源码正常运行默认关闭此模式。
