# 公开源码的数据与凭据边界

本公开整理副本不包含原有 SQLite 数据库、客户交付包、上传材料、真实学生作业、试卷原件、原始录屏或 Git 历史。框架依赖、虚拟环境和构建产物由使用者在自己的环境生成。

## 演示数据

`backend/app/seed/demo_data.py` 使用张同学等示例称呼、G1-001 等示例编号和虚构班级，`learning_data.py` 提供程序化的示例学习记录。首次运行在新的本地数据目录初始化。它们是功能演示用数据，不是对原始客户数据库做简单改名后的导出。

不要将真实姓名、学号、成绩、试卷、作业或其他个人资料上传至公开演示环境。当前系统没有完整的多用户身份认证与数据隔离。

## 模型服务与密钥

- 真实 AI 功能通过配置的模型服务发出请求，教学上下文可能包含班级和学生信息，因此演示只使用虚构内容。
- 密钥通过使用者自己的本地环境变量配置，不进入前端、仓库或共享发布包。
- `.env.example` 必须保持密钥为空；不要上传填写后的 `.env`。
- Windows 构建只生成空模板，默认关闭模拟上传，不收集构建者的 API Key。
- 如果历史密钥已经泄露，应由所有者在服务商控制台撤销或轮换；移除文件不会撤销凭据。

## 公开边界

此文档说明整理边界，不代表代码经过完整安全审计或系统已经适合直接对公网开放。旧接口、共享可写数据、模型调用额度及上传功能需要在正式公网部署前另行评估。本轮不添加产品功能或改变现有业务流程。
