# 演示数据和体验范围

## 已有数据

后端首次启动会创建新的本地 SQLite 数据库，由源码中的种子函数写入虚构教师、班级、6 名示例学生及历史作业/作答/学习记录。公开副本没有携带旧数据库。请使用新的演示数据目录，不连接客户数据库。

不配置 API Key 时，可先浏览已有班级、学生及历史学情；教学目标解析、教案/作业生成及 AI 检查需要使用者自己的模型配置。本次整理没有新增无密钥完整交互模式或在线地址。

## 推荐演示顺序

1. 查看班级与学生已有学习记录，理解画像与薄弱知识点。
2. 配置模型后，输入教学目标并检查生成草稿。
3. 教师确认目标，再生成并审核教案或统一作业。
4. 使用虚构作答资料演示教师确认、程序计分与画像更新。

当前界面流程以 README 和实际导航为准，不将历史专项训练/总管家模块当作当前完整入口。

## 两个已有演示开关

- `ZHJ_DEMO_UPLOAD=1`：仅针对代码指定的虚构学生及 PDF 上传使用预设答案，页面持续标注模拟；默认关闭，不等同于识别真实 PDF。
- `ENABLE_TEST_DEMO_GENERATION=1`：离线测试专用的预置生成开关，不将它包装成真实模型调用。

后续截图和视频将使用虚构数据制作；在完成检查前，不把客户录屏、原始作业或密钥配置页面加入仓库。
