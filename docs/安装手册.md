# 智教英航安装手册

## 一、运行条件

源码运行需要 Windows、Python 3.11 或以上、Node.js、pnpm（也可以使用 npm）和网络连接。AI 功能需要 DeepSeek API 密钥。

## 二、安装后端依赖

在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
```

如果系统禁止执行 PowerShell 脚本，可以在当前窗口执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

## 三、安装前端依赖

```powershell
cd frontend
pnpm install
cd ..
```

没有 pnpm 时可以使用 `npm install`。

## 四、配置 DeepSeek

在启动后端的同一个 PowerShell 窗口中设置密钥：

```powershell
$env:DEEPSEEK_API_KEY = "你的密钥"
$env:DEEPSEEK_MODEL = "deepseek-flash"
```

不要把真实密钥写入 Git 或发送到公开仓库。源码模式下，后端不会自动读取根目录 `.env`；请在启动窗口设置环境变量。根目录 `.env.example` 是配置项参考。Windows 打包程序才会读取可执行程序同目录的 `.env`。

## 五、启动项目

打开第一个 PowerShell 窗口：

```powershell
.\.venv\Scripts\Activate.ps1
$env:DEEPSEEK_API_KEY = "你的密钥"
python -m uvicorn app.main:app --app-dir backend --reload --port 8001
```

再打开第二个 PowerShell 窗口：

```powershell
cd frontend
pnpm run dev
```

浏览器打开 Vite 输出的地址，通常是 `http://localhost:5173`。后端健康检查地址为 `http://localhost:8001/api/v1/health`。

## 六、Windows 本地程序

`packaging` 文件夹包含 Windows 打包脚本。构建前需要安装 PyInstaller：

```powershell
python -m pip install pyinstaller
powershell -ExecutionPolicy Bypass -File .\packaging\build_windows.ps1
```

生成的程序会放在 `release\智教英航`。公开版构建不需要密钥，只生成空的 `.env.example`，不会复制构建者的 API Key。使用者完整解压后，可在本机复制 `.env.example` 为 `.env` 并填写自己的密钥，再启动程序。不要分享填写后的 `.env` 或本地 data 文件夹。

本次公开整理不提供已有 exe 或发布 ZIP；Windows 打包流程需要另行验证。源码首次启动生成虚构学生与历史学习数据，但 AI 生成仍需要真实模型配置。

## 七、常见问题

- 页面空白：确认后端和前端都已启动，不要直接打开 `frontend\index.html`。
- AI 报未配置密钥：在启动后端的同一个 PowerShell 窗口重新设置密钥并重启后端。
- 8001 端口被占用：关闭占用程序后重启，或同步修改前端 API 地址和后端端口。
- 作业上传失败：确认文件是当前作业对应的 Word 或文字型 PDF，且题号和答案清晰可提取。
