# 配套资料清单

- `backend/`：FastAPI 后端、数据模型、业务接口、种子数据和测试。
- `frontend/`：React + TypeScript 前端页面和样式。
- `packaging/`：Windows 本地程序打包脚本和启动脚本。
- `README.md`：项目概览和开发者快速启动说明。
- `docs/使用手册.md`：教师演示和日常使用步骤。
- `docs/安装手册.md`：源码运行、AI配置和 Windows 打包说明。
- `docs/开发记录.md`：开发思路、生成式 AI 协作证据、验证记录和限制。
- `docs/privacy.md`：公开源码的数据和凭据边界。
- `docs/demo.md`：已有虚构种子数据与演示限制。

原始作品说明、比赛报告、口播稿、Office/PDF 文件和录屏未随公开源码迁移。后续只补入检查后的截图和案例材料，不将旧设计方案中的规划功能当作当前已完成功能。

出于安全和体积考虑，配套包不包含 API 密钥、SQLite 数据库、安装依赖目录、Git 历史和教程视频。运行时会自动创建新的本地数据库；AI 密钥按安装手册配置。
